# Tic-Tac-Toe Game
A clean, responsive Tic-Tac-Toe web game built using HTML, CSS, and JavaScript. The application features turn tracking, win and tie detection with visual highlights, dynamic UI updates, and full game reset capabilities.

## Features
* **Two-Player Gameplay:** Turn-based system for Player X and Player O.
* **Win Detection:** Automatically checks all 8 winning combinations and highlights the winning tiles.
* **Draw State:** Detects ties when all 9 moves are played without a winner.
* **Overlay Announcement:** Popup screen announcing game results with options to start a new game.
* **Responsive Styling:** Modern grid UI with custom hover states and responsive viewport sizing.

## Technologies Used
* **HTML5:** Page structure, semantic tags, and interactive button grid layout.
* **CSS:** Flexbox positioning, absolute overlays, CSS transitions and custom styling.
* **JavaScript (ES6):** DOM selection/manipulation, event handling, array iterations, conditional logic, and state management.

## Project Structure
* `index.html` - Page markup and game structure.
* `app.css` - UI layout, grid styles, color scheme, and popup overlay effects.
* `app.js` - Game engine handling move tracking, board conditions, and reset functions.

## How to Run
1. Clone the repository:
   git clone https://github.com/codes-by-ali/tic-tac-toe-game.git
2. Navigate to the project directory:
   cd tic-tac-toe-game
3. Open `index.html` in any web browser.
